# 🚀 Code Compass

Code Compass is an AI-powered coding assistant that helps users:

- 💻 Ask programming questions
- 📝 Explain code
- 🐞 Debug errors
- 🤖 Get AI-generated coding solutions

## Technologies Used

- React.js
- Vite
- FastAPI
- Python
- Google Gemini API
- Axios

## How to Run

### Backend

cd backend
uvicorn main:app --reload
Frontend
cd frontend
npm install
npm run dev

Open:

http://localhost:5173
